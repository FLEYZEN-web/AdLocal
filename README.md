# SMART MERCH — Frontend Components & Modals

Проєкт реалізації компонентів дизайн-системи та інтерактивних модулів для **SMART MERCH**.

## Структура проєкту

- [`index.html`](index.html) — головна сторінка-навігація для швидкого переходу між завданнями.
- [`src/styles/tokens.css`](src/styles/tokens.css) — глобальні токени кольорів (Background `#080A08`, Card `#151915`, Border `#292E29`, Accent `#C6FF36`, Error `#FF5B5B`), радіусів, відступів та типографіки Inter.
- [`src/styles/components/forms.css`](src/styles/components/forms.css) — базові стилі для `input`, `textarea`, `select`, кнопок та станів (`:hover`, `:focus`, `.error`, `:disabled`, `.is-loading`).
- [`forms.html`](forms.html) — вітрина компонентів форм та всіх UI-станів.
- [`modals.html`](modals.html) — каталог продукції з інтерактивними модальними вікнами для детальної інформації про мерч.
- [`modals.css`](modals.css) — стилі карток товарів, модального вікна, бейджів наявності та адаптивної сітки.
- [`modals.js`](modals.js) — логіка відкриття/закриття модалок, динамічного заповнення даними, блокування скролу та доступності.
